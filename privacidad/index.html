Política de privacidad

clasp segundo cerebro · actualizada el 25 de noviembre de 2026

«clasp segundo cerebro» es una aplicación de uso personal de Jonatan Cardona Casas. No está abierta al público: la usa solo su dueño, con su propia cuenta de Google, para administrar sus propios scripts de Google Apps Script.

Qué datos usa

Con el permiso que da su dueño, la aplicación accede a su propio Gmail y a su propio Google Drive para guardar en Drive los adjuntos de sus correos, y a la API de Apps Script para desplegar y revisar esos scripts. No accede a datos de ninguna otra persona.

Qué se hace con ellos

Los datos no se venden, no se comparten con terceros y no se usan para publicidad ni para entrenar modelos. Se quedan en la cuenta de Google del dueño y en sus propios sistemas.

El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El acceso se puede revocar en cualquier momento desde myaccount.google.com/permissions.
